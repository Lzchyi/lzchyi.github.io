Key details

Small surface, serious boundaries.

01

Open source

MIT-licensed code and documented assets, with internal compatibility names preserved for safe upgrades.

02

No AI required

Local deterministic ranking and summaries work without a provider key. AI is optional BYOK.

03

Verified releases

GitHub Actions publishes checksummed page bundles and the Kindle updater validates every file.

04

Stock-friendly

Manual KUAL launch, visible HOME, failsafe exit, and an installer scoped to its owned paths.
